# 🏡 Rafa Imobiliária

Site simples de uma imobiliária fictícia, criado como **projeto de estudo** para praticar HTML, CSS e JavaScript puro, sem frameworks ou bibliotecas.

> ⚠️ Este é um projeto de treino. A imobiliária, os imóveis, os preços e os dados de contato são fictícios.

## ✨ Funcionalidades

- Menu fixo no topo com navegação suave entre as seções
- Seção de abertura com chamada para ação
- Lista de imóveis gerada com JavaScript a partir de um array de objetos
- Filtro por categoria: casas, apartamentos e terrenos
- Preços formatados em reais (`toLocaleString`)
- Formulário de contato com validação de nome e telefone
- Layout responsivo, que se adapta a celular e computador
- Tema escuro automático, de acordo com a preferência do sistema

## 🛠️ Tecnologias

- **HTML5**: estrutura semântica da página
- **CSS3**: variáveis CSS, Flexbox, Grid, media queries e `prefers-color-scheme`
- **JavaScript (ES6)**: manipulação do DOM, eventos, `filter`, `map` e template strings

## 📁 Estrutura do projeto

```
rafa-imobiliaria/
├── index.html   # estrutura e conteúdo da página
├── style.css    # estilos e cores
└── script.js    # filtro de imóveis e formulário
```

## 🚀 Como executar

1. Baixe o repositório.
2. Abra a pasta do projeto.
3. Dê dois cliques no arquivo `index.html` para abrir no navegador.

Não é preciso instalar nada.

## ✏️ Como personalizar

- **Cores:** altere as variáveis CSS no começo do `style.css`, dentro de `:root`.
- **Imóveis:** edite o array `imoveis` no começo do `script.js` para adicionar, remover ou mudar itens.

## 📚 O que pratiquei

- Organização de um projeto em três arquivos separados
- Criação de elementos na página de forma dinâmica com JavaScript
- Uso de eventos (`click` e `submit`) e validação de formulário
- Design responsivo com CSS Grid e Flexbox
- Suporte a modo claro e escuro com variáveis CSS
